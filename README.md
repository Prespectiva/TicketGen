# TicketGen — генератор вариантов экзаменационных билетов

Десктопное приложение для преподавателей: банк вопросов по темам и сложности,
шаблоны билетов, генерация серий с одинаковым баллом, экспорт в DOCX и PDF.
Учебная практика УП.01, Репенко Я. А., ИСП-341.

## Стек

- Python 3.10+, PyQt6 (интерфейс), SQLite (база tickets.db)
- python-docx и reportlab (экспорт), Poetry (зависимости)
- pytest (тесты), black и flake8 (качество кода)

## Архитектура

Многослойная, паттерн MVC:
- `ticketgen/views` — окна и вкладки (View)
- `ticketgen/controllers` — AppController (Controller, сигналы = Observer)
- `ticketgen/logic` — генератор, подсчёт баллов, импорт CSV, экспорт (Factory),
  выгрузка в Moodle
- `ticketgen/data` — Database (Singleton) и репозитории (Repository)
- `ticketgen/domain` — сущности (dataclass)

## Установка и запуск

    pip install poetry
    poetry install
    poetry run python -m ticketgen.seed_data   # тестовые данные (необязательно)
    poetry run python main.py

## Тесты и проверка кода

    poetry run pytest
    poetry run black --check .
    poetry run flake8

## Предметы

Каждая тема относится к предмету (дисциплине). Предметы и темы заводятся
в окне «Предметы и темы…» на вкладке «Банк вопросов». Там же есть фильтр по
предмету. У шаблона тоже указывается предмет: в его правилах предлагаются
только темы этого предмета.

## Импорт вопросов

Пустой шаблон (только строка заголовков) сохраняется кнопкой «Шаблон CSV» на
вкладке «Банк вопросов» и сразу открывается в Excel — остаётся вписать вопросы. Пример с ошибочными строками: `examples/questions_example.csv`
(столбцы: дисциплина;тема;сложность;тип;вопрос;ответ; первый столбец можно
назвать «предмет»).

## Выгрузка в Moodle

На вкладке «Результаты» кнопка «Экспорт в Moodle…» сохраняет билеты в Moodle
XML или GIFT:
- все билеты серии — каждый билет в своей категории «Серия / Билет № N»,
  из каждой категории в Moodle собирается свой тест;
- только выбранный билет — один тест.

В Moodle: «Банк вопросов → Импорт». Вопросы становятся «Эссе», эталонный ответ
попадает в информацию для оценщика, вес сложности — в балл вопроса.

## Оформление билета

На вкладке «Шаблоны» кнопка «Оформление билета…» задаёт:
- вид документа: экзаменационный или зачётный билет, контрольная или
  самостоятельная работа, тест (или свой вариант); от него зависит слово
  перед номером — «Билет № 1» или «Вариант № 1»;
- эмблему в левом верхнем углу, заголовок — по центру рядом с ней (картинка
  копируется в папку `logos`; кнопка «Последняя эмблема» ставит ту, которой
  пользовались последней);
- строку для ФИО и группы студента и место для подписи преподавателя.

Справа в окне сразу виден предпросмотр билета. Оформление попадает в DOCX и PDF.

## Документация

Документация собирается Sphinx из папки `docs`: руководство пользователя,
руководство разработчика, архитектура и справочник API из docstrings.
Готовый HTML лежит в репозитории в папке `docs/build/html` — откройте
`docs/build/html/index.html` в браузере.

Пересобрать после изменений:

    poetry add --group dev sphinx sphinx-rtd-theme   # один раз
    poetry run sphinx-build -b html docs/source docs/build/html
