TicketGen — генератор вариантов экзаменационных билетов
========================================================

**TicketGen** — настольное приложение для преподавателя. В нём ведётся банк
вопросов по предметам, темам и уровням сложности, задаются шаблоны билетов
и создаются серии билетов с одинаковым суммарным баллом. Готовые билеты,
эталонные ответы и сводная ведомость сохраняются в DOCX и PDF, а вопросы
выгружаются в Moodle.

Программа разработана на учебной практике УП.01 «Разработка программных
модулей программного обеспечения для компьютерных систем»
(специальность 09.02.07, ГБПОУ НСО «Новосибирский электромеханический
колледж»). Разработчик — Репенко Я. А., группа ИСП-341.
