Справочник API
==============

Справочник собран автоматически из docstrings исходного кода расширением
``sphinx.ext.autodoc``. Аргументы, возвращаемые значения и исключения
оформлены в docstrings по стилю Google (разделы ``Args``, ``Returns``,
``Raises``) и разбираются расширением ``sphinx.ext.napoleon``. У каждого
объекта есть ссылка «[исходный код]» на его текст.

Разделы идут по слоям приложения снизу вверх: от сущностей и базы данных
к контроллеру и окнам.
